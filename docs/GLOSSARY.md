# Glossary of Stellar & Soroban Terms

- **Stroop**: The smallest atomic unit of Stellar currency (1 XLM = 10,000,000 Stroops).
- **Soroban**: The smart contract platform native to the Stellar Network.
- **Protocol 22**: The current Stellar protocol upgrade introducing state storage enhancements and compiler optimizations.
- **SAC (Stellar Asset Contract)**: Smart contract representation of native Stellar classic assets.
- **StrKey**: Stellar standard address encoding format (e.g. Ed25519 public keys starting with 'G').
- **XDR (External Data Representation)**: Binary serialization standard used for Stellar transaction envelopes.
- **TTL (Time to Live)**: The number of ledgers a Soroban storage entry remains active before needing rent renewal.
