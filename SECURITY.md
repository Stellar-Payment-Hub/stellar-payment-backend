# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The Stellar Payment Hub team takes the security of smart contracts, cryptographic keys, and user assets very seriously.

If you discover a vulnerability:
1. **DO NOT** open a public GitHub issue.
2. Email full vulnerability details, reproduction steps, and potential exploit vectors to **security@stellar-payment-hub.org**.
3. We acknowledge reports within 24 hours and provide an estimated remediation timeline.
4. Responsible disclosure bounties may be awarded via the Stellar Community Fund.
